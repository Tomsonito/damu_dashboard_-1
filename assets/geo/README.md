# Границы областей Казахстана

Сюда нужно положить `kz_regions.geojson` — контуры двадцати областей.
Без него вид «Карта Казахстана» показывает подсказку вместо графика.

## Требования к файлу

- **актуальные границы** — после 2022 года, с областями Абай, Жетісу и Ұлытау.
  Файл старше даст три пустых области
- в свойствах каждой области есть её название; имя поля указывается
  в `config.yaml` → `geo.feature_key` (по умолчанию `properties.name`)
- названия должны совпадать с теми, что в данных, буква в букву.
  Если не совпадут — понадобится словарь соответствия, как `REGION_MAP`
  в `etl/load_budget.py`

## Почему здесь, а не в data/

`data/` восстанавливается запуском ETL и в git не попадает.
Границы так не восстановишь — файл должен ездить вместе с проектом.

Читается с диска при отрисовке. Наружу за ним никто не ходит: дашборд
работает во внутренней сети, и карта обязана обходиться без интернета.
