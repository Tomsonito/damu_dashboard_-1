# Границы областей Казахстана

Файл: **`kaz_admbnda_adm1_2024.json`** (~1 МБ, 20 областей).

Источник — пакет [arodionoff/geokz](https://github.com/arodionoff/geokz),
папка `maps`, набор `kaz_admbnda_adm1_2024`. Административное деление на
январь 2024, то есть **с тремя новыми областями** 2022 года: Абай, Жетісу,
Ұлытау. Лицензия CC-BY-4.0.

Исходно это shapefile из пяти файлов; в GeoJSON сконвертирован через
mapshaper.org — прямо в браузере, наружу ничего не отправлялось.

## Как названия связаны с данными

В файле названия лежат в трёх вариантах: `ADM1_EN`, `ADM1_KK`, `ADM1_RU`.
Берём русский — он ближе всего к тому, что в базе. Какое поле читать,
указано в `config.yaml` → `geo.feature_key`.

Совпали четырнадцать названий из двадцати. Шесть расхождений перечислены
в `config.yaml` → `geo.region_map`:

| В данных | В файле границ |
|---|---|
| Абай | Абайская |
| Жетісу | Жетысуская |
| Ұлытау | Улытауская |
| г. Алматы | Алматы |
| г. Астана | Астана |
| г. Шымкент | **Чимкент** — старое написание, через «Ч» |

Если область не найдётся в файле, карта покажет список ненайденных вместо
графика. Молча пропавший регион хуже явной ошибки: он просто не закрасился
бы, и никто не заметил.

## Почему здесь, а не в data/

`data/` восстанавливается запуском ETL и в git не попадает.
Границы так не восстановишь — файл должен ездить вместе с проектом.

Читается с диска при отрисовке. Проверено по сетевым запросам: при показе
карты наружу не уходит **ни одного** обращения. Это обязательное условие —
дашборд работает во внутренней сети без интернета.

## Если понадобится заменить

Годятся только наборы с двадцатью областями. Проверка одна: есть ли Абай,
Жетісу и Ұлытау. Популярные бесплатные источники не годятся, проверено:
geoBoundaries — данные 2017 года, 16 областей; GADM 4.1 — до реформы.
